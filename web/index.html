What each agent does

Goal Agent

Reads the student's goal in plain English ("I want to become an ML engineer, light workload") and turns it into a structured objective: career track weights, workload, credit limit, graduation target, and electives they asked for or want to avoid.

Constraint Agent

Owns every rule: prerequisites, co-requisites, odd/even term offerings, live seat availability, credit limits and degree requirements. It filters valid options and finally runs the guardrail validation on every roadmap.

Planning Agent

Searches the space of valid schedules (depth-first search with backtracking over a CSP), prioritising long prerequisite chains, resolving "one of" prerequisite rules and balancing difficulty using real pass rates. It extends the timeline only if no plan fits.

Adaptation Agent

Watches the live registrar feed. When a course fills up or is cancelled, a course is dropped or failed, or a goal changes, it re-plans the roadmap automatically and shows exactly what moved.
